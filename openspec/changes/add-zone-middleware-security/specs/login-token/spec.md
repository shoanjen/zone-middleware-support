# Spec Delta

## Purpose

为 Zone 生态提供自研的用户登录令牌能力:以加密安全随机数生成不透明令牌(opaque token),服务端在 Redis 中保存令牌与用户信息的映射,提供签发、解析、滑动续期、撤销(登出与踢下线)与多端策略配置,不依赖任何开源鉴权组件。

## ADDED Requirements

### Requirement: 令牌签发

SHALL 提供令牌签发方法:以加密安全随机数生成不少于 128 位的字母数字不透明令牌;签发时 MUST 在 Redis 中保存令牌到用户信息的映射,并设置过期时间——默认 7 天, MUST 可通过配置自定义。

#### Scenario: 签发返回令牌

- **WHEN** 以用户标识调用签发方法
- **THEN** 返回不少于 32 位的不透明令牌,两次签发结果不同,且该令牌可被解析出同一用户信息

#### Scenario: 默认过期时间

- **WHEN** 上游不做任何配置即签发令牌
- **THEN** 令牌生存期为 7 天

#### Scenario: 自定义过期时间

- **WHEN** 上游将过期时间配置为 1 小时后签发令牌
- **THEN** 令牌生存期为 1 小时

### Requirement: 令牌解析与校验

SHALL 提供令牌解析方法:合法且未过期的令牌 MUST 返回签发时保存的用户信息;不存在的令牌、已过期令牌与已撤销令牌 MUST 返回失败标识(返回 null)而不抛出异常。

#### Scenario: 合法令牌解析

- **WHEN** 以刚签发的合法令牌调用解析方法
- **THEN** 返回签发时保存的用户信息

#### Scenario: 非法令牌返回 null

- **WHEN** 以不存在的随机字符串调用解析方法
- **THEN** 返回 null,不抛出异常

#### Scenario: 撤销后令牌失效

- **WHEN** 令牌被撤销后调用解析方法
- **THEN** 返回 null

### Requirement: 滑动续期

校验通过时 SHALL 默认将令牌生存期自动重置为完整 TTL(滑动过期);上游 MUST 可通过配置关闭该行为,关闭后生存期自签发起固定不变。

#### Scenario: 访问续期

- **WHEN** 令牌已存在 6 天,此时解析校验通过(默认配置)
- **THEN** 该令牌生存期重置,自当前时刻起仍有完整 TTL

#### Scenario: 关闭续期

- **WHEN** 上游配置关闭滑动续期后,令牌已存在 6 天时解析校验
- **THEN** 校验按剩余生存期执行,生存期不被重置

### Requirement: 令牌撤销

SHALL 提供两类撤销方法:按令牌撤销(登出)与按用户撤销其全部令牌(踢下线);撤销 MUST 立即生效,被撤销令牌的后续解析即失败。

#### Scenario: 登出撤销

- **WHEN** 以某令牌调用按令牌撤销方法后立即解析该令牌
- **THEN** 解析返回 null

#### Scenario: 踢下线撤销

- **WHEN** 某用户持有多枚有效令牌时,以该用户标识调用按用户撤销方法
- **THEN** 该用户全部令牌解析均返回 null

### Requirement: 多端策略

SHALL 支持多端并存与单端互斥两种登录策略, MUST 可配置:默认多端并存——为同一用户再次签发不影响既有令牌;配置单端互斥后,再次签发 MUST 撤销该用户全部既有令牌。

#### Scenario: 默认多端并存

- **WHEN** 为同一用户连续签发两枚令牌(默认配置)
- **THEN** 两枚令牌解析均成功

#### Scenario: 单端互斥踢旧

- **WHEN** 上游配置单端互斥后,为已有有效令牌的用户再次签发
- **THEN** 新令牌解析成功,该用户全部旧令牌解析返回 null

### Requirement: 令牌请求头承载

登录令牌 MUST 经请求头 `Zone-Auth-Token` 携带;SHALL 提供从当前请求解析该请求头的取值方法,请求未携带或值为空时 MUST 返回 null 而不抛出异常。

#### Scenario: 从请求头取令牌

- **WHEN** 请求头 `Zone-Auth-Token` 携带令牌时调用取值方法
- **THEN** 返回该令牌字符串

#### Scenario: 无令牌返回 null

- **WHEN** 请求未携带 `Zone-Auth-Token` 请求头时调用取值方法
- **THEN** 返回 null,不抛出异常
